3  Reading practice

Can you say what a plot will look like from its specification alone? You have the vocabulary; now read with it. Ten plots follow, ending in a cube. For each one: read the specification aloud before looking at the picture, then check the picture against what you said. The English sentence is given under each plot. Try to say it yourself first.

3.1 Gold medals by country

Which country won the most gold, and by how much? medals holds one row per country, with its counts of gold, silver and bronze:

medals: all 5 rows
country gold silver bronze
USA 46 37 38
China 38 31 22
Great Britain 29 17 19
Russia 19 18 9
Germany 17 10 15
  • R
  • Python
  • Julia
  • JavaScript
data(medals) + bar + x(country) + y(gold)
data(medals) + bar + x(col.country) + y(col.gold)
data(medals) + bar + x(:country) + y(:gold)
plot(data(medals), bar, x(col.country), y(col.gold))

“Given the medals: bars, x is country, y is gold.” A bar measures an amount from zero, so the amount needs a continuous axis and the category takes the other one. The bindings put countries on x and gold on y. There is no transform here. bar draws the numbers exactly as the table gives them.

3.2 The same bars, horizontal

A medal table is usually printed as a list, with the leader at the top. The same five counts can be read that way.

  • R
  • Python
  • Julia
  • JavaScript
data(medals) + bar + x(gold) + y(country)
data(medals) + bar + x(col.gold) + y(col.country)
data(medals) + bar + x(:gold) + y(:country)
plot(data(medals), bar, x(col.gold), y(col.country))

“Given the medals: bars, x is gold, y is country.” Swap which axis carries the category and the bars become horizontal. There is no “horizontal bar” atom, and no argument that turns the bars. The sentence already says which axis holds the category, so the orientation follows from the bindings.

3.3 One measurement’s shape

The first two plots drew five counts that were already in the table. Often a table holds only measurements, and no counts.

Do petal lengths gather around one typical value, or do they separate into groups? One measurement answers that, and it comes from a new table. iris_flowers holds one row per flower: three measurements, and the species the flower belongs to.

iris_flowers: first 5 of 150 rows
sepal_length sepal_width petal_length species
5.1 3.5 1.4 setosa
4.9 3.0 1.4 setosa
4.7 3.2 1.3 setosa
4.6 3.1 1.5 setosa
5.0 3.6 1.4 setosa
  • R
  • Python
  • Julia
  • JavaScript
data(iris_flowers) + bar * bin + x(petal_length)
data(iris_flowers) + bar * bin + x(col.petal_length)
data(iris_flowers) + bar * bin + x(:petal_length)
plot(data(iris_flowers), layer(bar, bin), x(col.petal_length))

“Given the iris flowers: bars derived by bin, x is petal length.” The * derives the counts: bin cuts the axis into bins and counts the rows in each, and bar draws them. You did not bind y. bin invents the count itself, so the y axis is labeled Count. Note the two peaks. Plot eight explains them.

3.4 The same question, smoothly

A histogram draws the shape as flat steps, one per bin, and sometimes you want one smooth curve instead. The measurement this time is life expectancy, across the 142 countries.

gapminder_2007: first 5 of 142 rows
country continent year life population gdp
Afghanistan Asia 2007 43.828 31889923 974.5803
Albania Europe 2007 76.423 3600523 5937.0295
Algeria Africa 2007 72.301 33333216 6223.3675
Angola Africa 2007 42.731 12420476 4797.2313
Argentina Americas 2007 75.320 40301927 12779.3796
  • R
  • Python
  • Julia
  • JavaScript
data(gapminder_2007) + line * density + x(life)
data(gapminder_2007) + line * density + x(col.life)
data(gapminder_2007) + line * density + x(:life)
plot(data(gapminder_2007), layer(line, density), x(col.life))

“Given gapminder 2007: a line derived by density, x is life.” The question is the same as the histogram’s: how is this measurement distributed? The answer is drawn differently. density replaces bin, and line replaces bar, because a smooth estimate is one curve, not many bars.

3.5 One strip of dots per continent

The density curve in plot four reduced 142 countries to one shape. Do the continents differ in life expectancy, and how widely do the countries inside each one vary? Both answers are visible when every country is shown.

  • R
  • Python
  • Julia
  • JavaScript
data(gapminder_2007) + point + x(continent) + y(life)
data(gapminder_2007) + point + x(col.continent) + y(col.life)
data(gapminder_2007) + point + x(:continent) + y(:life)
plot(data(gapminder_2007), point, x(col.continent), y(col.life))

“Given gapminder 2007: points, x is continent, y is life.” A categorical x gives each category a slot on the axis, and that category’s points sit in a strip above the slot. The same rule placed bars on country slots in plot one. Here it applies to a different mark. A plot shaped like this one has a name: the strip plot.

3.6 The typical value per continent

You often want one number per continent, its average, instead of 142 separate values.

  • R
  • Python
  • Julia
  • JavaScript
data(gapminder_2007) + bar * mean + x(continent) + y(life)
data(gapminder_2007) + bar * mean + x(col.continent) + y(col.life)
data(gapminder_2007) + bar * mean + x(:continent) + y(:life)
plot(data(gapminder_2007), layer(bar, mean), x(col.continent),
  y(col.life))

“Given gapminder 2007: bars derived by mean, x is continent, y is life.” Each bar is one continent’s average. Here y(life) names the column that mean averages, because a transform that reads a column must be told which column.

3.7 Five countries across the decades

Plots four to six show only 2007. A question about change needs many years, so the next plot uses another table.

How has life expectancy changed since 1952, and did five Asian countries change at the same rate? gapminder_asia holds one row per country and year, so each country appears many times.

gapminder_asia: first 5 of 60 rows
country continent year life population gdp
China Asia 1952 44.00000 556263527 400.4486
China Asia 1957 50.54896 637408000 575.9870
China Asia 1962 44.50136 665770000 487.6740
China Asia 1967 58.38112 754550000 612.7057
China Asia 1972 63.11888 862030000 676.9001
  • R
  • Python
  • Julia
  • JavaScript
data(gapminder_asia) + line + x(year) + y(life) + color(country)
data(gapminder_asia) + line + x(col.year) + y(col.life) + color(col.country)
data(gapminder_asia) + line + x(:year) + y(:life) + color(:country)
plot(data(gapminder_asia), line, x(col.year), y(col.life),
  color(col.country))

“Given gapminder Asia: lines, x is year, y is life, color by country.” On a line, a categorical color first splits the rows into one line per category, then colors them. One channel does two things, and you write it once.

3.8 Three species on one axis

Plot three showed two peaks in petal length, and the table has three species. How do three species make two peaks?

  • R
  • Python
  • Julia
  • JavaScript
data(iris_flowers) + bar * bin + x(petal_length) + color(species)
data(iris_flowers) + bar * bin + x(col.petal_length) + color(col.species)
data(iris_flowers) + bar * bin + x(:petal_length) + color(:species)
plot(data(iris_flowers), layer(bar, bin), x(col.petal_length),
  color(col.species))

“Given the iris flowers: bars derived by bin, x is petal length, color by species.” The left peak is setosa alone. The right peak is versicolor and virginica together, because their petal lengths overlap. All three histograms use the same bin edges, and each one is drawn where its own species’ values fall. Each fill is translucent under a solid outline, so every histogram stays visible. color splits the rows here into one histogram per species, by the same rule as in plot seven.

3.9 One panel per continent

Richer countries live longer across the world as a whole, as the first chapter showed. Is that also true inside each continent?

  • R
  • Python
  • Julia
  • JavaScript
data(gapminder_2007) + point + x(gdp, scale = "log") + y(life) | facet(continent)
data(gapminder_2007) + point + x(col.gdp, scale = "log") + y(col.life) | facet(col.continent)
data(gapminder_2007) + point + x(:gdp, scale = "log") + y(:life) |
  facet(:continent)
plot(data(gapminder_2007), point, x(col.gdp, { scale: "log" }),
  y(col.life), across(col.continent))

“Given gapminder 2007: points, x is gdp on a log scale, y is life, split into panel columns by continent.” Inside each continent, life expectancy also rises with income. The rise is clearest in Europe and Asia and least clear in Africa, where the points are most scattered. The | operator splits the plot into panel columns, one panel per category. All the panels share one pair of scales, so they can be compared. As in the first chapter, scale = "log" spreads out the countries that would otherwise crowd against the left edge.

3.10 Three measurements on three axes

Petal length alone left two species overlapping in plot eight. Two more measurements might separate them, if all three measurements can be seen at once.

  • R
  • Python
  • Julia
  • JavaScript
data(iris_flowers) + point +
  x(sepal_length) + y(sepal_width) + z(petal_length) +
  color(species)
(data(iris_flowers) + point +
  x(col.sepal_length) + y(col.sepal_width) + z(col.petal_length) +
  color(col.species))
data(iris_flowers) + point + x(:sepal_length) + y(:sepal_width) +
  z(:petal_length) + color(:species)
plot(data(iris_flowers), point, x(col.sepal_length), y(col.sepal_width),
  z(col.petal_length), color(col.species))

“Given the iris flowers: points, x is sepal length, y is sepal width, z is petal length, color by species.” The third dimension is not a different package, and not a different mark. It is one more position channel, and the same specification without z(petal_length) would draw a flat scatter. In the web edition the cube turns with a drag: drag right and the side facing you moves right, drag down and it tilts. Every angle hides some points and shows others, so turn the cube more than once.

3.11 What you just did

Those ten plots used twelve distinct words, and every plot reads left to right: data, mark, positions, refinements. A transform joined the mark and a facet came last, exactly where the first chapter put them. The same color split the bars and lines, and colored the points. The same * derived counts, means and densities. Each word meant the same thing in every plot that used it.

3.12 What comes next

Every sentence here was already written, so nothing asked you to choose a mark. Writing practice reverses that: it starts from a question and asks you to write the sentence.
