16  Text

Which point is which? text draws a string, a piece of text such as a name or a number, at each (x, y) position. It is point’s sibling: both place one glyph per row. A point’s glyph is a dot by default. A text mark’s glyph is a string, and that string comes from a column, through the label channel. This chapter uses it three ways: to name the points of a scatter, to print a value on a bar, and to write a note on a plot.

16.1 The mark and its content

A point tells you where a row is; it cannot tell you which row. Five countries drawn as dots are five points with nothing to say which country is which:

medals: all 5 rows
country gold silver bronze
USA 46 37 38
China 38 31 22
Great Britain 29 17 19
Russia 19 18 9
Germany 17 10 15
  • R
  • Python
  • Julia
  • JavaScript
data(medals) + point + x(gold) + y(silver) +
  x_label("Gold") + y_label("Silver") +
  title("Five countries, and no names")
(data(medals) + point + x(col.gold) + y(col.silver) +
  x_label("Gold") + y_label("Silver") +
  title("Five countries, and no names"))
data(medals) + point + x(:gold) + y(:silver) + x_label("Gold") +
  y_label("Silver") + title("Five countries, and no names")
plot(data(medals), point, x(col.gold), y(col.silver), x_label("Gold"),
  y_label("Silver"), title("Five countries, and no names"))

“Given the medals: points, x is gold, y is silver.”

Replace point with text and bind label to country, and each row’s name is drawn at its position:

  • R
  • Python
  • Julia
  • JavaScript
data(medals) + text + x(gold) + y(silver) + label(country) +
  x_label("Gold") + y_label("Silver") +
  title("The same five, named")
(data(medals) + text + x(col.gold) + y(col.silver) + label(col.country) +
  x_label("Gold") + y_label("Silver") +
  title("The same five, named"))
data(medals) + text + x(:gold) + y(:silver) + label(:country) +
  x_label("Gold") + y_label("Silver") + title("The same five, named")
plot(data(medals), text, x(col.gold), y(col.silver), label(col.country),
  x_label("Gold"), y_label("Silver"), title("The same five, named"))

“Given the medals: text, x is gold, y is silver, label by country.”

That is the whole difference between the two marks. point draws the same dot at every row’s position. text draws one of the row’s own values there instead.

16.2 Both at once: the labeled scatter

A dot marks one position on the panel. A word is much wider than a dot, so a name on its own only shows roughly where its row is. The two marks can be drawn together: layer a point mark and a text mark on the same x and y, with the + operator. The dot gives the exact position and the string gives the name. That is a labeled scatter, built from two marks rather than a third mark of its own.

Each style() applies to the mark written before it, so style(size = 5, color = "#9e9e9e") colors the dots and not the words. Without a nudge, each label is drawn centered on its dot, so style(nudge = "up") moves every label above its dot:

  • R
  • Python
  • Julia
  • JavaScript
data(medals) + point + style(size = 5, color = "#9e9e9e") +
  text + x(gold) + y(silver) + label(country) + style(nudge = "up") +
  x_label("Gold") + y_label("Silver") +
  title("Located by the dot, named just above")
(data(medals) + point + style(size = 5, color = "#9e9e9e") +
  text + x(col.gold) + y(col.silver) + label(col.country) + style(nudge = "up") +
  x_label("Gold") + y_label("Silver") +
  title("Located by the dot, named just above"))
data(medals) + point + style(size = 5, color = "#9e9e9e") + text +
  x(:gold) + y(:silver) + label(:country) + style(nudge = "up") +
  x_label("Gold") + y_label("Silver") +
  title("Located by the dot, named just above")
plot(data(medals), point, style({ size: 5, color: "#9e9e9e" }), text,
  x(col.gold), y(col.silver), label(col.country), style({ nudge: "up" }),
  x_label("Gold"), y_label("Silver"),
  title("Located by the dot, named just above"))

“Given the medals: points and also text, x is gold, y is silver, label by country, with nudge up.”

16.2.1 Nudging the label off its point

Up is only one of four directions, and it is not always the side with room. A dot near the top of the panel, or one with a neighbor just above it, has no space for its name there. Those labels need a different direction. style(nudge = ) shifts a text label off its (x, y). It takes one direction: "up", "down", "left", or "right":

  • R
  • Python
  • Julia
  • JavaScript
data(medals) + point + style(size = 5, color = "#9e9e9e") +
  text + x(gold) + y(silver) + label(country) + style(nudge = "right") +
  x_label("Gold") + y_label("Silver") +
  title("The same, nudged right")
(data(medals) + point + style(size = 5, color = "#9e9e9e") +
  text + x(col.gold) + y(col.silver) + label(col.country) + style(nudge = "right") +
  x_label("Gold") + y_label("Silver") +
  title("The same, nudged right"))
data(medals) + point + style(size = 5, color = "#9e9e9e") + text +
  x(:gold) + y(:silver) + label(:country) + style(nudge = "right") +
  x_label("Gold") + y_label("Silver") + title("The same, nudged right")
plot(data(medals), point, style({ size: 5, color: "#9e9e9e" }), text,
  x(col.gold), y(col.silver), label(col.country),
  style({ nudge: "right" }), x_label("Gold"), y_label("Silver"),
  title("The same, nudged right"))

You do not give a distance. The engine sets it from the font size, far enough that the word does not touch a dot of the default size. That is why nudge asks only for a direction. A nudge is one fixed shift, the same for every label, and nothing in the data changes it. jitter and dodge work differently: they compute each mark’s offset from the data, so marks can move by different amounts. Only text accepts a nudge. A point or a bar has no label to move, so the engine refuses the setting there and names the mark that does.

16.2.2 repel: moving labels off each other

A nudge shifts every label the same way, so it moves each label off its own dot and does nothing else. When the labels collide with each other, one fixed shift moves them all together and the words still overlap. Thirty European countries are enough to show it:

gm_europe: first 5 of 30 rows
country continent year life population gdp
Albania Europe 2007 76.423 3600523 5937.030
Austria Europe 2007 79.829 8199783 36126.493
Belgium Europe 2007 79.441 10392226 33692.605
Bosnia and Herzegovina Europe 2007 74.852 4552198 7446.299
Bulgaria Europe 2007 73.005 7322858 10680.793
  • R
  • Python
  • Julia
  • JavaScript
data(gm_europe) + point + style(color = "#9e9e9e") +
  text + x(gdp) + y(life) + label(country) +
  x_label("GDP per person") + y_label("Life expectancy") +
  title("Thirty countries, named")
(data(gm_europe) + point + style(color = "#9e9e9e") +
  text + x(col.gdp) + y(col.life) + label(col.country) +
  x_label("GDP per person") + y_label("Life expectancy") +
  title("Thirty countries, named"))
data(gm_europe) + point + style(color = "#9e9e9e") + text + x(:gdp) +
  y(:life) + label(:country) + x_label("GDP per person") +
  y_label("Life expectancy") + title("Thirty countries, named")
plot(data(gm_europe), point, style({ color: "#9e9e9e" }), text,
  x(col.gdp), y(col.life), label(col.country), x_label("GDP per person"),
  y_label("Life expectancy"), title("Thirty countries, named"))

Every name is drawn on its own dot, and where the countries crowd together the words overlap. A nudge would move all thirty words the same distance in the same direction, so the same words would still overlap.

repel solves that. It is one of the four collision modifiers, with jitter, dodge and stack, so it is written after the mark with *, not inside style(). It measures where the labels and the dots actually are, then moves each label off the words around it:

  • R
  • Python
  • Julia
  • JavaScript
data(gm_europe) + point + style(color = "#9e9e9e") +
  text * repel + x(gdp) + y(life) + label(country) +
  x_label("GDP per person") + y_label("Life expectancy") +
  title("The same thirty, moved apart")
(data(gm_europe) + point + style(color = "#9e9e9e") +
  text * repel + x(col.gdp) + y(col.life) + label(col.country) +
  x_label("GDP per person") + y_label("Life expectancy") +
  title("The same thirty, moved apart"))
data(gm_europe) + point + style(color = "#9e9e9e") + text * repel +
  x(:gdp) + y(:life) + label(:country) + x_label("GDP per person") +
  y_label("Life expectancy") + title("The same thirty, moved apart")
plot(data(gm_europe), point, style({ color: "#9e9e9e" }),
  layer(text, repel), x(col.gdp), y(col.life), label(col.country),
  x_label("GDP per person"), y_label("Life expectancy"),
  title("The same thirty, moved apart"))

“Given gapminder Europe: points and also text derived by repel, x is gdp, y is life, label by country.”

Notice three things in this plot. Every label is drawn just outside its dot, so no word covers the dot it names. A label with other words near it moves to whichever side has room. A label with space around it stays where it started, directly above its dot. The first two follow from one rule: repel pulls each label toward its own dot, and pushes it away from every other word and every dot, its own included.

In a more crowded plot, repel can move a label much further from its dot. Once the gap is larger than the height of one line of text, gog draws a thin line from the dot to the word, so you can still see which dot the name belongs to. No label in this plot moved that far, so none has a line.

The placement is deterministic. It uses no random-number generator and does not read the computer’s clock, so the same specification draws the same picture every time. It does depend on the order of the rows, though. repel settles the overlaps pair by pair, in the order of the rows, so the same rows in a different order can end with some labels in different places.

Sometimes no placement keeps every label apart. repel then still draws every label, and gog prints a message saying how many still overlap. Which names to leave out is your decision, so repel never removes one. In this plot all thirty fit, so gog prints no message.

Three things give crowded labels more room: fewer rows, a smaller style(size = ), and a larger plot. theme(width =, height =) sets the plot’s size in pixels, and the Composition chapter explains it.

Fewer rows is often the right choice. On a large table you usually name only the few rows that matter: give the text layer its own table that holds just those rows, as A note is a layer does with one row. In the web edition, clicking a dot on a plot with brush() shows its values beside it, which Selection calls a stamp. Stamps help you choose those rows. A stamp is gone when the page reloads, while a text label is part of the specification and is drawn every time.

In the next plot, the dots come from gapminder_2007, which holds all 142 countries. The names come from gm_populous, the ten countries with the most people in 2007. gm_populous has the same columns, so the text layer reads gdp and life from it:

The gdp axis uses a log scale (Scales), which gives the many poorer countries more room. repel moves the names off the 132 unnamed dots too, though they come from another table. It moves a name off those dots only a little, never far enough for gog to draw a thin line. So a name can still cover some of them: United States covers several at the top right, and Bangladesh covers two. A halo keeps such a name readable.

16.3 Number labels: the value on each mark

A label does not have to be a name, and it does not have to be drawn on a scatter. A bar shows which country won more. To read how much more, a reader has to measure each bar against the axis, and that measurement is only an estimate. Sometimes the number itself is the answer. Bind a column that holds numbers and each row’s value is drawn. By default, a whole number is printed without a decimal point, and any other number is rounded to at most three decimal places. Layer text over bar to print each bar’s height. Without a nudge, each number is centered on its bar’s top edge, and the edge crosses the digits. style(nudge = "up") moves each number just above its bar:

  • R
  • Python
  • Julia
  • JavaScript
data(medals) + bar + style(color = "steelblue") +
  text + x(country) + y(gold) + label(gold) + style(nudge = "up") +
  y_label("Gold medals") +
  title("Each bar labeled with its height")
(data(medals) + bar + style(color = "steelblue") +
  text + x(col.country) + y(col.gold) + label(col.gold) + style(nudge = "up") +
  y_label("Gold medals") +
  title("Each bar labeled with its height"))
data(medals) + bar + style(color = "steelblue") + text + x(:country) +
  y(:gold) + label(:gold) + style(nudge = "up") + y_label("Gold medals") +
  title("Each bar labeled with its height")
plot(data(medals), bar, style({ color: "steelblue" }), text,
  x(col.country), y(col.gold), label(col.gold), style({ nudge: "up" }),
  y_label("Gold medals"), title("Each bar labeled with its height"))

“Given the medals: bars and also text, x is country, y is gold, label by gold, with nudge up.”

Each bar now carries its number, so the difference between the USA’s 46 and China’s 38 can be read without the axis.

The medals table already holds the numbers. A bar chart that counts rows computes its numbers itself. In bar * count, the count transform writes the number of rows in each bar into a column called count. text * count uses the same transform, so label(count) can print that column on each bar. As in the medals plot, the numbers are nudged up:

  • R
  • Python
  • Julia
  • JavaScript
data(gapminder_2007) + bar * count + x(continent) +
  text * count + label(count) + style(nudge = "up") +
  title("Each bar labeled with its count")
(data(gapminder_2007) + bar * count + x(col.continent) +
  text * count + label(col.count) + style(nudge = "up") +
  title("Each bar labeled with its count"))
data(gapminder_2007) + bar * count + x(:continent) + text * count +
  label(:count) + style(nudge = "up") +
  title("Each bar labeled with its count")
plot(data(gapminder_2007), layer(bar, count), x(col.continent),
  layer(text, count), label(col.count), style({ nudge: "up" }),
  title("Each bar labeled with its count"))

“Given gapminder 2007: bars derived by count, x is continent, and also text derived by count, label by count, with nudge up.”

Africa’s bar is labeled 52, and Oceania’s bar is labeled 2.

The same sentence labels horizontal bars, with the category on y instead of x. The bars grow to the right. The text layer reads the same positions, so each number is centered on the right end of its bar. style(nudge = "right") moves it just past that end:

  • R
  • Python
  • Julia
  • JavaScript
data(gapminder_2007) + bar * count + y(continent) +
  text * count + label(count) + style(nudge = "right")
(data(gapminder_2007) + bar * count + y(col.continent) +
  text * count + label(col.count) + style(nudge = "right"))
data(gapminder_2007) + bar * count + y(:continent) + text * count +

plot(data(gapminder_2007), layer(bar, count), y(col.continent),

Africa’s 52 is past the end of the longest bar, and Oceania’s 2 is past the shortest. The axis’s margin already holds Africa’s 52. A label that would not fit inside the panel widens its axis instead (Scales).

A histogram is labeled the same way. The bin transform also writes a column called count, the number of rows in each bin. So text * bin with label(count) prints how many countries fall in each bin of life expectancy:

  • R
  • Python
  • Julia
  • JavaScript
data(gapminder_2007) + bar * bin + x(life) +
  text * bin + label(count) + style(nudge = "up")
(data(gapminder_2007) + bar * bin + x(col.life) +
  text * bin + label(col.count) + style(nudge = "up"))
data(gapminder_2007) + bar * bin + x(:life) + text * bin + label(:count) +
  style(nudge = "up")
plot(data(gapminder_2007), layer(bar, bin), x(col.life), layer(text, bin),
  label(col.count), style({ nudge: "up" }))

“Given gapminder 2007: bars derived by bin, x is life, and also text derived by bin, label by count, with nudge up.”

The last bin, from about 78 to 83 years, holds the most countries: 32.

Add proportion to both layers, and each bar is a share of all the countries instead of a count. proportion turns each count into a share, so the rows hold a column called proportion and no count. The text layer therefore names label(proportion):

  • R
  • Python
  • Julia
  • JavaScript
data(gapminder_2007) + bar * bin * proportion + x(life) +
  text * bin * proportion + label(proportion, decimals = 2) +
  style(nudge = "up")
(data(gapminder_2007) + bar * bin * proportion + x(col.life) +
  text * bin * proportion + label(col.proportion, decimals = 2) +
  style(nudge = "up"))
data(gapminder_2007) + bar * bin * proportion + x(:life) +
  text * bin * proportion + label(:proportion, decimals = 2) +
  style(nudge = "up")
plot(data(gapminder_2007), layer(bar, bin, proportion), x(col.life),
  layer(text, bin, proportion), label(col.proportion, { decimals: 2 }),
  style({ nudge: "up" }))

“Given gapminder 2007: bars derived by bin and proportion, x is life, and also text derived by bin and proportion, label by proportion with 2 decimal places, with nudge up.”

The last bin is now labeled 0.23. Its 32 countries make a share of 0.2254 of the 142, and decimals = 2 rounds the share to two decimal places, as Number labels explains. These rows hold no count, so label(count) is refused, and the message names the transform that replaced it:

data(gapminder_2007) + bar * bin * proportion + x(life) +

16.10 Why label is a channel

A setting is a value you type into the sentence. You might expect to type a label into the sentence in the same way, like a title. A label is not a title: it is one value per row, and that makes it data. One rule of the grammar decides whether a label is a setting or a channel: data reaches a mark only through a channel. That makes label a channel, so no mark takes the words themselves as an argument. A fixed note is therefore a table with one row, given to data(), and never a value given to style().

Only text accepts label; every other mark refuses it, which is why a labeled scatter is point + text and never a label on point. text requires a label: the label is part of the mark’s minimum syllable, as x and y are. Ask for a text mark with no label and the engine refuses, and says what to write instead, as What it refuses shows. text is the mark, and label is the channel that carries the column it draws.

style(angle = ) degrees, counterclockwise from horizontal

16.14 What it refuses

A text mark always refuses three things: a missing label, the shape channel, and any pattern. It refuses group only when no statistic and no dodge uses it. The label is part of the mark’s minimum syllable, as x and y are: with no string, a text mark has nothing to draw. The engine refuses and names the channel to add:

A reader who knows point will try its channels on text. color draws with a categorical column, and size and opacity draw with a continuous one, as on a point. shape is refused outright, because it cannot change a string. A point’s glyph can change shape because the dot itself says nothing. A text mark’s glyph is the string itself, so there is nothing for shape to change:

16.15 In short

A text mark will not draw without a label, and no other mark accepts one. Its words come from a column, so a fixed note is a table with one row. repel draws every label and reports how many still overlap, because which names to leave out is your decision.

16.16 What comes next

Without repel, row order never moves a word: each one is drawn at the position its own row gives it. For a path, row order decides which rows are joined: the mark joins each row to the next, in the order the table holds them.
