18  Rule

Where is the line you want to compare every value against? Most marks read two positions. rule reads one and draws a line there, across the whole panel along the other axis. That line is a reference line at a threshold. A short line drawn in from the edge of the panel is a tick. One tick for each row makes a rug, which shows where the observations are.

Most plotting libraries draw a reference line and a rug with three marks: a vertical reference line, a horizontal one, and a rug. gog has one. A vertical and a horizontal reference line differ only in which axis holds the position. gog finds that axis from the columns, as it does for a bar.

18.1 A line at a threshold

Is a country’s life expectancy above 70 or below it? On a scatter the reader has to find 70 on the axis and judge each point against it. With a line at 70, each point is compared with the line instead of with the axis. gapminder_2007 holds 142 countries in 2007, one row for each. life_bands holds three thresholds, one row each: 60, 70 and 80 years. Here they are as a scatter of life expectancy against income, with a line at each threshold. The plots in this chapter turn the gridlines off with theme(grid = "none"), so the reference lines are the only lines across the panel, and style(color = "firebrick") draws them in a color apart from the blue points.

The sentence names rule once, and the plot draws three lines. That is the mark’s most useful property: its position is a column, not a number. life_bands holds three values, one per line. Add a fourth row and a fourth line appears with no change to the plot’s sentence at all.

Every channel works this way: color(band) names a column, not a color. A column can hold a different value in each row, so a rule can draw a different line in each panel of a plot. The continent_means table has two columns, continent and life: each continent’s mean life expectancy in 2007, computed from gapminder_2007 and rounded to one decimal. Split the plot into one panel per continent with facet(continent), and each panel shows its own continent’s line:

Each panel shows only its own continent’s row of continent_means: the line is drawn at 54.8 years in Africa and at 77.6 in Europe. A rule’s values are placed on the axis like any other column’s, on a log scale too. In polar the same rule becomes a ring, as In polar shows.

A rule takes no transform, so it cannot compute a reference for you. What it refuses shows that refusal. Which reference you need decides which mark you write:

Mark The reference it draws
rule a line at each value in a column you supply (A line at a threshold)
line * mean the mean of each group, joined into a profile; drawn here as a radar in In polar
ribbon * bounds a band between a low column and a high one (A pre-computed band)
zone * bounds a block across the panel, between the same two (Thickness as data)
line * straight the least-squares line through the points, a sloped reference line (straight: the least-squares line)

The line rises about 16.6 years of life expectancy for each tenfold rise in income, such as from $1,000 to $10,000. The countries far below it live much shorter lives than the line gives for their income.

A line with a slope and a point you choose, rather than one fitted to the data, is drawn from its two end points. Put them in a two-row table whose columns are the plot’s own, and draw it with line. Every flower lies below the line, so every petal is shorter than its sepal. The line runs only between its two end points, so choose them near the ends of the axes. An end point outside the data stretches the axis, which is why the petal axis here reaches 8. For a slope b through the point (x0, y0), the height at an end x1 is y0 + b * (x1 - x0).

18.2 Horizontal or vertical

Nothing in the read-aloud sentences under the two plots above said “horizontal”. The mark took the direction from the columns instead. life_bands has a life column and no gdp column, and the plot’s y is life. So only the y axis has its column in the rule’s table. The rule marks each value on that axis and spans the other one.

A threshold on income needs a vertical line, and there is no second mark for it. Give the rule a table that holds gdp instead, and the same word draws the line vertically. Here the table is one row holding one income, $10,000, written inside the sentence:

data(gapminder_2007) + point + x(gdp) + y(life) +
  data(data.frame(gdp = 10000.0), name = "gdp_threshold") + rule +
    style(color = "firebrick", pattern = "dashed") +
  x_label("GDP per person") + y_label("Life expectancy") +
  title("The same mark, the other axis") +
  theme(grid = "none")

  data({"gdp": [10000.0]}, name = "gdp_threshold") + rule +
    style(color = "firebrick", pattern = "dashed") +
  x_label("GDP per person") + y_label("Life expectancy") +
  title("The same mark, the other axis") +
  theme(grid = "none"))
data(gapminder_2007) + point + x(:gdp) + y(:life) +
  data((gdp = [10000],), name = "gdp_threshold") + rule +
  style(color = "firebrick", pattern = "dashed") +
  x_label("GDP per person") + y_label("Life expectancy") +
  title("The same mark, the other axis") + theme(grid = "none")
plot(data(gapminder_2007), point, x(col.gdp), y(col.life),
  data({ gdp: [10000] }, { name: "gdp_threshold" }), rule,
  style({ color: "firebrick", pattern: "dashed" }),
  x_label("GDP per person"), y_label("Life expectancy"),
  title("The same mark, the other axis"), theme({ grid: "none" }))

“Given gapminder 2007: points, x is gdp, y is life; then given one row with gdp 10000: a rule colored firebrick, with pattern dashed.”

The table holds gdp, the plot’s x, so the line is vertical.

18.3 A rug of ticks

A scatter shows where each country is on two axes at once. Another question asks only how the countries spread along the income axis. A rug tick reads one position too. It marks one value and extends a short distance into the panel from its edge. That is a threshold line, only shorter, and the setting that makes it short is style(reach = "edge"):

  • R
  • Python
  • Julia
  • JavaScript
data(gapminder_2007) + point + x(gdp) + y(life) + style(opacity = 0.45) +
  rule + x(gdp) + style(reach = "edge") +
  x_label("GDP per person") + y_label("Life expectancy") +
  title("Where the countries are on the income axis") +
  theme(grid = "none")
(data(gapminder_2007) + point + x(col.gdp) + y(col.life) + style(opacity = 0.45) +
  rule + x(col.gdp) + style(reach = "edge") +
  x_label("GDP per person") + y_label("Life expectancy") +
  title("Where the countries are on the income axis") +
  theme(grid = "none"))
data(gapminder_2007) + point + x(:gdp) + y(:life) +
  style(opacity = 0.45) + rule + x(:gdp) + style(reach = "edge") +
  x_label("GDP per person") + y_label("Life expectancy") +
  title("Where the countries are on the income axis") +
  theme(grid = "none")
plot(data(gapminder_2007), point, x(col.gdp), y(col.life),
  style({ opacity: 0.45 }), rule, x(col.gdp), style({ reach: "edge" }),
  x_label("GDP per person"), y_label("Life expectancy"),
  title("Where the countries are on the income axis"),
  theme({ grid: "none" }))

“Given gapminder 2007: points, x is gdp, y is life, and also rules, x is gdp, with reach edge.”

The rule names x(gdp) even though the points already named it. This layer has no table of its own, so it reads the scatter’s, which holds both gdp and life. The rule could be placed on either axis, so it has to say which one it is on.

style(reach = ) takes one of two words: panel, the default, and edge. A tick’s length comes from the panel: 3.5 percent of the panel’s height, or of its width for a rug up the side. It is never less than 4 pixels and never more than 14. The minimum keeps a tick visible in a small facet, and the maximum keeps it short in a large plot. Every setting except reach works as on any rule.

Look along the bottom. Each tick is one country, drawn at its own income. Below $5,000 the ticks merge into one solid block: 66 of the 142 countries are in the first tenth of the income axis. The scatter holds the same countries but spreads them up the other axis, so the crowding is harder to see.

In general a rug puts the one-dimensional distribution of one column in the margin of a plot that already shows something else. You read the spread of gdp and still see the scatter, in the same panel.

A second plot can show the same spread. Here a histogram of gdp, cut into 30 bins by bin(30), is drawn under the scatter, and the two plots share one gdp axis. Composition shows how plots are put together this way.

  • R
  • Python
  • Julia
  • JavaScript
(data(gapminder_2007) + point + x(gdp) + y(life) +
   y_label("Life expectancy") +
   title("The same incomes, counted below the scatter") +
   theme(grid = "none")) /
  (data(gapminder_2007) + bar * bin(30) + x(gdp) +
     x_label("GDP per person") + theme(height = 150, grid = "none"))
((data(gapminder_2007) + point + x(col.gdp) + y(col.life) +
   y_label("Life expectancy") +
   title("The same incomes, counted below the scatter") +
   theme(grid = "none")) /
  (data(gapminder_2007) + bar * bin(30) + x(col.gdp) +
     x_label("GDP per person") + theme(height = 150, grid = "none")))
(data(gapminder_2007) + point + x(:gdp) + y(:life) +
  y_label("Life expectancy") +
  title("The same incomes, counted below the scatter") +
  theme(grid = "none")) /
  (data(gapminder_2007) + bar * bin(30) + x(:gdp) +
  x_label("GDP per person") + theme(height = 150, grid = "none"))
below(plot(data(gapminder_2007), point, x(col.gdp), y(col.life),
  y_label("Life expectancy"),
  title("The same incomes, counted below the scatter"),
  theme({ grid: "none" })),
  plot(data(gapminder_2007), layer(bar, bin(30)), x(col.gdp),
  x_label("GDP per person"), theme({ height: 150, grid: "none" })))

“Given gapminder 2007: points, x is gdp, y is life, above bars derived by bin into 30, x is gdp.”

The first bar is the tallest: 40 countries below about $1,900. Together with the next two bars, up to about $5,200, it holds 66 countries, the same 66 the rug draws as a solid block of ticks.

18.3.1 The other axis

The rug so far has been along the bottom, on income. Life expectancy has a distribution of its own, and overlapping points hide it on the y axis too. A rug is not only for the horizontal axis. The position you name on the layer decides which axis it is on. Write y(life) instead of x(gdp) and the ticks run up the left edge. Write both, as two layers, and the scatter has a rug along the bottom and another up the left at once:

  • R
  • Python
  • Julia
  • JavaScript
data(gapminder_2007) + point + x(gdp) + y(life) + style(opacity = 0.45) +
  rule + x(gdp)  + style(color = "firebrick", reach = "edge") +
  rule + y(life) + style(color = "firebrick", reach = "edge") +
  x_label("GDP per person") + y_label("Life expectancy") +
  title("Both margins, from two layers") +
  theme(grid = "none")
(data(gapminder_2007) + point + x(col.gdp) + y(col.life) + style(opacity = 0.45) +
  rule + x(col.gdp)  + style(color = "firebrick", reach = "edge") +
  rule + y(col.life) + style(color = "firebrick", reach = "edge") +
  x_label("GDP per person") + y_label("Life expectancy") +
  title("Both margins, from two layers") +
  theme(grid = "none"))
data(gapminder_2007) + point + x(:gdp) + y(:life) +
  style(opacity = 0.45) + rule + x(:gdp) +
  style(color = "firebrick", reach = "edge") + rule + y(:life) +
  style(color = "firebrick", reach = "edge") + x_label("GDP per person") +
  y_label("Life expectancy") + title("Both margins, from two layers") +
  theme(grid = "none")
plot(data(gapminder_2007), point, x(col.gdp), y(col.life),
  style({ opacity: 0.45 }), rule, x(col.gdp),
  style({ color: "firebrick", reach: "edge" }), rule, y(col.life),
  style({ color: "firebrick", reach: "edge" }), x_label("GDP per person"),
  y_label("Life expectancy"), title("Both margins, from two layers"),
  theme({ grid: "none" }))

“Given gapminder 2007: points, x is gdp, y is life, and also rules, x is gdp, colored firebrick, with reach edge, and also rules, y is life, colored firebrick, with reach edge.”

Each rug names one axis, and both read the scatter’s table. A single rule layer that names both is refused, because a rule draws one line per row, placed by one column. The message suggests two layers, one per axis, as What it refuses shows.

The left edge shows a different distribution from the bottom edge. The ticks are dense above 70, thinnest between 60 and 70, and a little denser again from 60 down to 40. Of the 142 countries, 83 are above 70 and 43 below 60, with only 16 between. This is a distribution with two groups and a thin stretch between them, not a single group. The bottom rug cannot show this, because its ticks are placed by income. In the scatter it is harder to see, because the same countries are spread over two axes.

18.4 Coloring the lines

The three threshold lines in the plot under A line at a threshold are all drawn alike, and nothing says what each one stands for. Give each line its own color instead, and the legend prints the band’s name beside that color. A rule draws one line per row of its table, so color gives each row its own color. life_bands has a band column naming each threshold, and that is the column to use. The points are light gray and the lines are 3 pixels wide, set by style(size = 3), twice the default of 1.5, so the three colors are easy to see against the points:

  • R
  • Python
  • Julia
  • JavaScript
data(gapminder_2007) + point + x(gdp) + y(life) + style(color = "lightgray") +
  data(life_bands) + rule + color(band) + style(size = 3) +
  x_label("GDP per person") + y_label("Life expectancy") +
  title("One line per band, named in the legend") +
  theme(grid = "none")
(data(gapminder_2007) + point + x(col.gdp) + y(col.life) + style(color = "lightgray") +
  data(life_bands) + rule + color(col.band) + style(size = 3) +
  x_label("GDP per person") + y_label("Life expectancy") +
  title("One line per band, named in the legend") +
  theme(grid = "none"))
data(gapminder_2007) + point + x(:gdp) + y(:life) +
  style(color = "lightgray") + data(life_bands) + rule + color(:band) +
  style(size = 3) + x_label("GDP per person") +

18.7 In polar: the ring and the spoke

Wind comes from a compass direction, so its speed can be drawn on a circle, as a radar chart. A target speed on that chart is a threshold like any other. In polar one of the two axes is bent into a circle. The question is what shape the line takes then. The mark does one thing: it draws a line at one position and spans the whole of the other axis. In polar that is unchanged. A polar plot has two axes, the angle and the radius. A rule that spans the angle is a ring, and one that spans the radius is a spoke: a straight line from the center to the rim, the outer edge of the circle. The Polar chapter explains how the circle itself is built.

18.8 Transforms it takes

A transform computes new values from the rows, and the mark draws those values instead of the rows. The table lists every transform by kind. A rule takes none of them, so each one is in the Refuses column:

Kind Takes Refuses
Counting — bin, count, density, proportion
Summaries — sum, mean, median, max, min, quantile
Fitted lines — smooth, straight
Running total — cumulative
Pairs: a low and a high — range, confidence, deviation, smooth_band, straight_band, bounds
Collision modifiers — dodge, stack, jitter, repel
Layouts of a whole picture — partition, flow, layout, cluster

A rule is placed by one column and spans the whole panel on the other axis. A transform needs a second position, to group by or to put its result on, and a rule reads only one. To draw a value computed from the rows, write a mark that takes the transform: line * mean joins the means of the groups. For a band between a low column and a high column you already have, write ribbon * bounds or zone * bounds. The line, ribbon and zone chapters draw them. What it refuses shows rule * mean refused.

A rule is a stroke, so pattern takes the five stroke patterns, solid among them. style(pattern = "hatch") is refused, as What it refuses shows. "hatch" is a fill texture, for a filled region. bar, area, box and ribbon take it, and so does zone, the next chapter.

What a rule refuses follows from the same geometry. There is no shape, because shape chooses the symbol a point is drawn with, such as a circle or a square, and a line is not drawn with one. There is no border either. What it refuses shows both refused.

The grid of every mark and every setting shows which other marks share this list. What a mark maps rather than sets is its row on the grid of marks and channels.

18.10 What it refuses

The first sentence you are likely to try is a bare rule on the plot’s own table. That table holds both position columns, so the rule could be placed on either axis. Nothing in the sentence says which axis is meant, so gog refuses rather than choosing one:

18.11 In short

A rule’s position is a column and never a number, so three thresholds are three rows. With its column on x the line is vertical, and on y horizontal. style(reach = "edge") makes it a rug tick, and in polar it is a ring or a spoke. A rule on the plot’s own table must name exactly one axis, or gog refuses it. It takes no transform, so you compute a mean in a table of its own.
