14  Box

How is each group spread out? box draws a box plot for each group, a summary of the measured column. A box spans the lower quartile to the upper, with a line at the median. Whiskers reach to the most extreme values within 1.5 times the interquartile range (IQR) of the box. Any values beyond that limit are outliers, drawn individually as dots. bar * mean gives only one number per group, while box shows how the whole group is spread. An interval needs a transform to supply its low and high values, while a box computes its whole summary itself. Boxes are vertical when the categories are on x and horizontal when they are on y; see Horizontal boxes.

The construction is John Tukey’s, from Exploratory Data Analysis (Tukey, 1977). His book gives two versions. The box-and-whisker plot runs its whiskers to the smallest and largest values, as Mary Eleanor Spear’s range bar (Spear, 1952) had done a quarter century earlier, in 1952. The schematic plot sets a fence 1.5 times the length of the box beyond each end of the box, and stops each whisker at the last value inside it. Each value beyond a fence is drawn on its own, as an outlier. Readers kept the first name, now usually shortened to box plot. Most software, gog included, gives that name to the schematic plot and draws it by default.

There is one difference from his book. Tukey’s box spans hinges: the median of the lower half of the values and the median of the upper half. To find them, sort the values and cut the sorted list in half; when the count is odd, the middle value belongs to both halves. Then take the median of each half. gog spans the lower and upper quartiles instead, as most software does. The two agree when a group has an odd number of values, and can differ slightly when the number is even. For the four values 1, 2, 3 and 4, the hinges are 1.5 and 3.5, while gog’s box runs from 1.75 to 3.25.

14.1 A summary per group

How do the three species differ in petal length, not only on average but in how widely each varies? Every box is built the same way. About half the flowers of a species fall inside the box, the middle 50% from the lower quartile to the upper. The line across the box is the median. Each whisker runs from the box to the most extreme value inside the fence. The separate dots are the outliers: flowers more than 1.5 times the IQR from the box. The whisker stops before them, and each one is drawn on its own.

14.3 How much to summarize

The box above draws five values for each continent, but the same table can also be drawn with every country, or with one value for each continent. In gog you make that choice by changing the mark or its transform; the table, x and y stay the same. point * jitter draws every row and reduces nothing: jitter only moves each point a little sideways, so that countries with close values do not hide one another. A box reduces each group to five values and still draws each outlier. interval * range keeps two values, the lowest row and the highest. point * mean draws one value, the mean. Each plot to the right reduces the data more, and drawing more values or fewer each has a cost. Drawing many values risks information overload: there are so many marks that the shape of the data is hard to see. Drawing few values causes information loss: whatever the rows held beyond those few values is no longer drawn. The left plot draws all 52 African countries, spread over 36.8 years, and it is hard to see where most of them lie. The box shows Africa in five values: the middle half runs from about 48 to 59 years, and the whiskers reach the lowest and highest countries. Asia’s Afghanistan is still a dot of its own. interval * range keeps only the two ends. Asia’s whisker reaches down to Afghanistan’s 43.8 years, and the plot does not show that only one country is that low. point * mean draws one value for each continent. It is the easiest to compare across continents, and it does not show how far apart Africa’s countries are.

So every amount of summary has one of the two costs, and no single amount is right for every plot. You can start from every row and summarize step by step, losing a little information at each step. Or you can start from a summary and add detail step by step, with a little more to read at each step. The question decides where to stop. To compare the continents’ averages, one value is enough. To find the countries far below the rest, draw the box or every row. A plot can also draw two amounts at once, a summary and the rows it summarizes. Here the boxes have a light fill and dark lines, and each country is a dark point over them. The box is written first because the layers are drawn in the order you write them, so the points land on top of the boxes (The + operator: layering):

  style(color = "lightsteelblue", border_color = "#2f4b7c", border_size = 1) +

  point * jitter + style(color = "#333333", size = 2, opacity = 0.7) +

The box gives each continent’s middle half at a glance, and the points show where every country lies inside it and beyond it.

14.4 Horizontal boxes

When the category names are long, or there are many of them, the boxes should be horizontal. Swap the two positions, and the plot is drawn with its axes exchanged. gog has no word like ggplot2’s coord_flip(), because it would be a second way to say the same thing. gog reads the two bindings and decides from them which axis carries the numbers, exactly as bar does.

  x_label("Life expectancy (years)") + y_label("Continent") +

  title("The same five distributions, horizontal"))

“Given gapminder 2007: boxes, x is life, y is continent.”

Compare it with the vertical version in Distribution across many groups. Every box, whisker and outlier dot keeps its place relative to its neighbors. Only the two axes have changed places. Afghanistan and Haiti are still the two dots beyond their continents’ whiskers. Everything later in this chapter works the same on either axis: the whisker rule, the color split, dodge and style().

14.5 Whiskers to the extremes

Sometimes you do not want outliers drawn separately. You want the whiskers to run to the true minimum and maximum. The box then shows the five-number summary: the minimum, the lower quartile, the median, the upper quartile and the maximum. The mark takes one parameter for this, a named option inside its parentheses: box(whiskers = "range"):

  • R
  • Python
  • Julia
  • JavaScript
data(gapminder_2007) + box(whiskers = "range") + x(continent) + y(life) +
  x_label("Continent") + y_label("Life expectancy (years)") +
  title("The same, with whiskers to the full range")
(data(gapminder_2007) + box(whiskers = "range") + x(col.continent) + y(col.life) +
  x_label("Continent") + y_label("Life expectancy (years)") +
  title("The same, with whiskers to the full range"))
data(gapminder_2007) + box(whiskers = "range") + x(:continent) +
  y(:life) + x_label("Continent") + y_label("Life expectancy (years)") +
  title("The same, with whiskers to the full range")
plot(data(gapminder_2007), box({ whiskers: "range" }), x(col.continent),
  y(col.life), x_label("Continent"), y_label("Life expectancy (years)"),
  title("The same, with whiskers to the full range"))

“Given gapminder 2007: boxes with whiskers to the range, x is continent, y is life.”

Now Afghanistan and Haiti are the ends of their whiskers rather than dots, and no value is drawn as an outlier. The default is "tukey": fences and outliers, the standard box plot. "range" draws the whole five-number summary. whiskers is not a setting, because it changes the summary itself: which values the whiskers reach. A setting changes only how the summary looks, such as its color or line width; Changing how a box looks shows them.

14.6 Why box needs no transform

An interval cannot draw without a transform to give it a low and a high. A box never needs one. An interval is only a shape, a span from a low value to a high one. Which low and high it spans is a real choice: a min–max range, a confidence interval, or a pre-computed pair. A box always draws the same kind of summary: quartiles, a median and whiskers. Only the whisker rule can change, through the mark’s own whiskers. A statistic that is always drawn by the same mark belongs inside that mark, not in a separate transform. So the shortest sentence that draws a box is box + x + y, with no transform. Adding any transform other than dodge is refused, and the message says what to write instead, as What it refuses shows.

The same principle keeps the channel vocabulary small: a value that only one mark can use is computed by that mark, not added to the channels every mark shares. In ggplot2 you can give a box its five values yourself, as five aesthetics: ymin, lower, middle, upper and ymax. If gog did the same, it would need five more channels. ymin and ymax could also give an interval or a ribbon its two ends, but lower, middle and upper would mean something only on a box. Instead the box computes its summary itself, and the channel vocabulary does not grow.

The table below sets the four marks side by side. Three of them read a low and a high value from a transform, and box computes its own summary:

Mark The spread it draws
interval * range a whisker from the low value to the high
ribbon * range the band between the two values, filled
line * range the two values as two separate strokes
box quartiles, median and whiskers, with no transform to write

box is also one of several marks that draw a distribution, and each answers a different question. bar * bin draws one variable’s histogram: how many values fall in each bin? interval draws a range or an error bar: between which two values do a group’s values fall? box gives the summary per group: where are its middle half, its median and its unusual values? The violin (ribbon * density) draws an estimate of the whole distribution that summary is computed from: where are the values dense, and where are they sparse? An interval can also span the box’s two quartiles: interval * range(0.25, 0.75) draws the same middle half, as A band between two quantiles shows.

The Interval chapter builds the same parts from three layers: the full range, the middle half and the median. Drawn beside a box on the same table, the box and the middle half match, and so does the median. The whiskers match only when the box runs them to the range. So the figure draws three plots: the default box, a box(whiskers = "range"), and the three layers:

The middle box runs its whiskers to the smallest and largest flower, as the gray range does, so all its parts match the three layers: the whiskers, the box and the median.

14.7 Coloring the boxes

The three species boxes in A summary per group are all one color, so only the species names on the axis identify each box. With a color per species, a reader can find the same species in another plot by its color. color gives each box its own hue and adds one legend that names the hues. Here color is mapped to the same column as x, so each species gets one box in its own color:

  title("The same distributions, colored by species"))
data(iris_flowers) + box + x(:species) + y(:petal_length) +
  color(:species) + x_label("Species") + y_label("Petal length (cm)") +
  title("The same distributions, colored by species")
plot(data(iris_flowers), box, x(col.species), y(col.petal_length),
  color(col.species), x_label("Species"), y_label("Petal length (cm)"),
  title("The same distributions, colored by species"))

Mapping color to a second category, such as an era, splits each category on x into one box per color. bar and interval split their categories the same way. 14.8 Transforms it takes

A transform computes new values from the rows, and the mark draws those values instead of the rows. The table lists, by kind, the transforms a box takes and the ones it refuses:

Kind Takes Refuses
Counting — bin, count, density, proportion
Summaries — sum, mean, median, max, min, quantile
Fitted lines — smooth, straight
Running total — cumulative
Pairs: a low and a high — range, confidence, deviation, smooth_band, straight_band, bounds
Collision modifiers dodge stack, jitter, repel
Layouts of a whole picture — partition, flow, layout, cluster

A box takes only one transform, dodge, so one figure shows it. It is the only mark that computes a summary with no transform written: it works out its own quartiles, median and whiskers from the rows, as Why box needs no transform explains. Every summary and every pair transform is refused, since the box has already done that work. The figure shows the same boxes twice, first without dodge and then with it.

A box refuses every transform in the Refuses column above. It computes its own summary, as Why box needs no transform explains, so it refuses the counts, the summaries and the pairs. For the same reason it refuses the fitted lines and the running total. A point, a bar or a line draws the counts, the summaries, the fitted lines and the running total. interval, ribbon, line and step draw the pairs. Of the collision modifiers, a box takes only dodge. A box’s position on the axis that carries the numbers is set by its values. Piling one box on another would move its quartiles away from the values they mark. stack piles up bars, areas and the dots of a dot plot, and places a label in each segment of a stacked bar. jitter moves each point a short way along the categorical axis, and repel moves text labels. partition, flow and cluster lay out rectangles, bands and branches, which zone, ribbon and path draw. layout places a network, which point, text and edge draw.

14.11 In short

For each group, a box draws quartiles, a median, whiskers to the most extreme values within 1.5 times the IQR, and a dot for each outlier. The summary is inside the mark, so a box refuses every statistic and takes only dodge. whiskers is its one parameter. Its line width and opacity are set once for the layer. gog’s box spans the quartiles, so when a group has an even number of values it can differ slightly from Tukey’s hinges.

A box occupies one slot on its axis, and its width carries no value from the table. Ribbon fills the band between a low value and a high one at every position along the axis.
