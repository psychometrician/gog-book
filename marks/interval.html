13  Interval

How far does each group reach, from its lowest value to its highest? interval draws a whisker at each position: a span from a low value to a high one, with a short line across each end, a cap. When the statistic has a center, such as a mean, a dot marks it. It is the mark that draws error bars and min–max ranges. A bar measures from a baseline up to a value. An interval has no baseline. It spans from a low value to a high value, and it needs both of them before it can draw. Whiskers are vertical when the categories are on x and horizontal when they are on y; see Horizontal whiskers.

Almost everyone calls this an error bar, and that name does not say what the whisker measures. Three different quantities are drawn as the same picture: a standard deviation, a standard error, and a confidence interval. On the same data, one can be several times longer than another. Nothing in the drawing says which one it is, and a reader with no caption cannot tell.

gog makes the sentence name the statistic instead. interval * range spans the observed extremes. interval * confidence(0.95) computes a confidence interval and states its level in the sentence. interval * bounds(lower, upper) reads two columns you computed yourself. The mark is the same whisker in all three; what differs is the transform, and the transform is written down. That is the law of Explicit Over Implicit, shown in one mark: the name error bar does not say which statistic it drew, and a written sentence must.

13.1 A range per group

How far do the petal lengths of each species reach, from the shortest to the longest? One whisker per species answers it, and a whisker needs a low value and a high value to span. The low value and the high value come from a transform, not from two extra channels. range reduces y to its minimum and maximum within each x group, and interval spans between them:

4.9 3.0 1.4 setosa

data(iris_flowers) + interval * range + x(species) + y(petal_length) +
  x_label("Species") + y_label("Petal length (cm)") +
  title("Range of petal length per species")
(data(iris_flowers) + interval * range + x(col.species) + y(col.petal_length) +
  x_label("Species") + y_label("Petal length (cm)") +
  title("Range of petal length per species"))

  x_label("Species") + y_label("Petal length (cm)") +
  title("Range of petal length per species")

  y(col.petal_length), x_label("Species"), y_label("Petal length (cm)"),
  title("Range of petal length per species"))

“Given the iris flowers: intervals derived by range, x is species, y is petal length.”

This sentence has the same shape as bar * mean. The difference is what the transform returns: mean returns one number per group, and range returns two. You name only the one variable whose spread you are asking about. The transform invents the two extents, and the mark spans them.

range is not the interval’s own transform. Three other marks read the same low and high value, and only the shape changes:

Mark derived by range Shape
ribbon * range the band between the two values, filled
line * range the two values as two separate strokes
step * range the same two boundaries, as staircases
interval * range one whisker per group

range is one of four pair transforms. A pair transform supplies a low value and a high value, where most transforms supply a single number. The other three are confidence, deviation and bounds, and each one works the same way in every row of that table. A mark that spans a pair takes all four.

13.2 The middle half of each group

A minimum and a maximum each come from a single row, so one unusual flower can set the whole whisker. To show the middle of a group instead of its extremes, give range two quantiles:

  • R
  • Python
  • Julia
  • JavaScript
data(iris_flowers) + interval * range(0.25, 0.75) + x(species) + y(petal_length) +
  x_label("Species") + y_label("Petal length (cm)") +
  title("Middle half of petal length per species")
(data(iris_flowers) + interval * range(0.25, 0.75) + x(col.species) + y(col.petal_length) +
  x_label("Species") + y_label("Petal length (cm)") +
  title("Middle half of petal length per species"))
data(iris_flowers) + interval * range(0.25, 0.75) + x(:species) +
  y(:petal_length) + x_label("Species") + y_label("Petal length (cm)") +
  title("Middle half of petal length per species")
plot(data(iris_flowers), layer(interval, range(0.25, 0.75)),
  x(col.species), y(col.petal_length), x_label("Species"),
  y_label("Petal length (cm)"),
  title("Middle half of petal length per species"))

“Given the iris flowers: intervals derived by range from 0.25 to 0.75, x is species, y is petal length.”

This spans the first quartile to the third, which is the interquartile range. range(0.1, 0.9) keeps the middle 80%, and any other pair works the same way. range written with no arguments means range(0, 1), so it still spans from the minimum to the maximum. Transforms gives the full account of the two arguments.

13.3 Three layers instead of one mark

A box draws five numbers in one mark, and you take all five or none. Draw the band and the full range as two layers, and the median as a third. You can give any of the three layers its own style, drop one, or replace one:

  • R
  • Python
  • Julia
  • JavaScript
data(iris_flowers) +
  interval * range + style(color = "darkgray") +
  interval * range(0.25, 0.75) + style(color = "steelblue", size = 8) +
  point * median + style(color = "gold", size = 5, opacity = 1) +
  x(species) + y(petal_length) +
  x_label("Species") + y_label("Petal length (cm)") +
  title("Petal length per species, drawn in three layers")
(data(iris_flowers) +
  interval * range + style(color = "darkgray") +
  interval * range(0.25, 0.75) + style(color = "steelblue", size = 8) +
  point * median + style(color = "gold", size = 5, opacity = 1) +
  x(col.species) + y(col.petal_length) +
  x_label("Species") + y_label("Petal length (cm)") +
  title("Petal length per species, drawn in three layers"))
data(iris_flowers) + interval * range + style(color = "darkgray") +
  interval * range(0.25, 0.75) + style(color = "steelblue", size = 8) +
  point * median + style(color = "gold", size = 5, opacity = 1) +
  x(:species) + y(:petal_length) + x_label("Species") +
  y_label("Petal length (cm)") +
  title("Petal length per species, drawn in three layers")
plot(data(iris_flowers), layer(interval, range),
  style({ color: "darkgray" }), layer(interval, range(0.25, 0.75)),
  style({ color: "steelblue", size: 8 }), layer(point, median),
  style({ color: "gold", size: 5, opacity: 1 }), x(col.species),
  y(col.petal_length), x_label("Species"), y_label("Petal length (cm)"),
  title("Petal length per species, drawn in three layers"))

“Given the iris flowers: intervals derived by range, and also intervals derived by range from 0.25 to 0.75, and also points derived by median, x is species, y is petal length.”

The gray whisker is the full range, the thick blue band is the middle half, and the gold dot is the median. Order decides what you can see. A later layer is painted over an earlier one, so the median is written last. Move it to the front of the sentence and the band draws over it, leaving almost nothing to see. If you have used ggplot2, this is the rule you already know: a geom_ added later draws on top. The dot is set opaque as well, since every mark is slightly translucent by default.

The three layers name the three statistics, and a box plot draws the same three and names none of them. This is not a box redrawn, though, and the difference is at the ends. A box stops its whiskers at a cutoff computed from the quartiles, and draws every point beyond that cutoff as an outlier. A box on this same data draws outlier dots for setosa and versicolor. They are absent here, because these whiskers run to the true minimum and maximum.

Because each statistic is its own layer, you can change one without touching the others. Widen the band to range(0.1, 0.9) and the plot reports a different statistic, with the same marks. Drop the gray layer and the y axis is scaled to the band rather than to the extremes. Add a third layer with another pair of quantiles, and you have the fan chart drawn over categories instead of along a line. A box is still the shorter sentence when you want the five numbers and the outlier rule together.

13.4 A confidence interval, with a center

How well is the average petal length of each species known? That is a different question from how far the flowers spread, and it needs a different statistic. range shows the full spread. For the uncertainty of the mean, use confidence. It computes a t-interval for each group’s mean, which is the confidence interval the opening named, and that interval widens when the group is small. It keeps the mean as the center of the span, and the mark draws a dot there. A whisker with a dot at its center is a pointrange.

  • R
  • Python
  • Julia
  • JavaScript
data(iris_flowers) + interval * confidence(0.95) + x(species) + y(petal_length) +
  x_label("Species") + y_label("Petal length (cm)") +
  title("95% CI of mean petal length")
(data(iris_flowers) + interval * confidence(0.95) + x(col.species) + y(col.petal_length) +
  x_label("Species") + y_label("Petal length (cm)") +
  title("95% CI of mean petal length"))
data(iris_flowers) + interval * confidence(0.95) + x(:species) +
  y(:petal_length) + x_label("Species") + y_label("Petal length (cm)") +
  title("95% CI of mean petal length")
plot(data(iris_flowers), layer(interval, confidence(0.95)),
  x(col.species), y(col.petal_length), x_label("Species"),
  y_label("Petal length (cm)"), title("95% CI of mean petal length"))

“Given the iris flowers: intervals derived by confidence at 95%, x is species, y is petal length.”

The level is the only parameter, so confidence(0.99) draws wider than confidence(0.95). confidence computes a t-interval and takes no other. For a z-interval, a bootstrap, or the standard errors a model already gave you, compute the two numbers yourself and pass them to bounds.

13.5 The spread of the data

How far is a typical flower from the average of its species? That is a question about the spread of the data, not about how well the average is known. The opening of this chapter named three quantities: a standard deviation, a standard error and a confidence interval. confidence draws the confidence interval. The standard deviation has a transform of its own, deviation:

  • R
  • Python
  • Julia
  • JavaScript
data(iris_flowers) + interval * deviation + x(species) + y(petal_length) +
  x_label("Species") + y_label("Petal length (cm)") +
  title("Mean petal length, with one standard deviation")
(data(iris_flowers) + interval * deviation + x(col.species) + y(col.petal_length) +
  x_label("Species") + y_label("Petal length (cm)") +
  title("Mean petal length, with one standard deviation"))
data(iris_flowers) + interval * deviation + x(:species) +
  y(:petal_length) + x_label("Species") + y_label("Petal length (cm)") +
  title("Mean petal length, with one standard deviation")
plot(data(iris_flowers), layer(interval, deviation), x(col.species),
  y(col.petal_length), x_label("Species"), y_label("Petal length (cm)"),
  title("Mean petal length, with one standard deviation"))

“Given the iris flowers: intervals derived by deviation, x is species, y is petal length.”

deviation alone reaches one standard deviation on each side of the mean. deviation(2) reaches two, so that band is four standard deviations wide. Like confidence it carries a center, so it draws a pointrange rather than a bare whisker.

The standard error has no transform of its own, and it does not need one. It is the standard deviation divided by the square root of the group size. confidence computes it internally and reports the interval built from it, which is what a reader of the plot needs.

deviation and confidence look alike and answer different questions. | puts two plots side by side on one page, and because both name petal_length on y they share that scale, drawn once down the left. The same operator splits one plot into panels when facet() is on its right instead, and Composition and Faceting have the rules for each. Here are the two statistics on the same fifty flowers per species:

  • R
  • Python
  • Julia
  • JavaScript
(data(iris_flowers) + interval * deviation + x(species) + y(petal_length) +
   y_label("Petal length (cm)") + title("Spread of the data")) |
  (data(iris_flowers) + interval * confidence + x(species) + y(petal_length) +
     y_label("") + title("Uncertainty of the mean"))
((data(iris_flowers) + interval * deviation + x(col.species) + y(col.petal_length) +
   y_label("Petal length (cm)") + title("Spread of the data")) |
  (data(iris_flowers) + interval * confidence + x(col.species) + y(col.petal_length) +
     y_label("") + title("Uncertainty of the mean")))
(data(iris_flowers) + interval * deviation + x(:species) +
  y(:petal_length) + y_label("Petal length (cm)") +
  title("Spread of the data")) |
  (data(iris_flowers) + interval * confidence + x(:species) +
  y(:petal_length) + y_label("") + title("Uncertainty of the mean"))
beside(plot(data(iris_flowers), layer(interval, deviation),
  x(col.species), y(col.petal_length), y_label("Petal length (cm)"),
  title("Spread of the data")),
  plot(data(iris_flowers), layer(interval, confidence), x(col.species),
  y(col.petal_length), y_label(""), title("Uncertainty of the mean")))

“Given the iris flowers: intervals derived by deviation, x is species, y is petal length, beside intervals derived by confidence, x is species, y is petal length.”

The bands on the right are less than a third as long, and the data is identical. The ratio is the same in all three species. The two statistics do not contradict each other. deviation describes how far the flowers are from their average, and measuring more of them does not make that band shorter. confidence describes how precisely the average itself is known. More flowers make it shorter: four times as many flowers make it half as long. That ratio comes from the group size, fifty flowers per species.

So choose by the caption you would write under the plot. “A versicolor petal is usually within half a centimeter of its species average” describes the left panel. “The average versicolor petal is 4.26 cm, and the interval reaches 0.13 cm on either side” describes the right one. Reporting one and meaning the other is the mistake the name error bar allows, and the reason gog asks you to name the statistic.

Which band is shorter also depends on the group size. With fifty flowers per species the confidence band is much shorter, as the plot shows. With only a few flowers per species it can be the longer one, because a t-interval widens when the group is small.

Whether a center exists is decided by the statistic, not by a setting. confidence and deviation compute a mean and range does not. So the shape follows from the statistic: a bare error bar for range, a pointrange for the other two. A setting can hide an existing center, as Hiding the center dot shows, but no setting adds one to range. A second layer does. point * mean over interval * range draws the same pointrange, as Three layers instead of one mark shows with the median. See Transforms for the whole range family.

13.6 Why interval needs a transform

Every plot so far has named a transform, and the rule behind that is worth stating on its own. A bar needs no transform, because the grammar already supplies its baseline: zero. bar + x + y draws. An interval has no such default. A low and a high are two numbers, and a plain y() supplies one. So the shortest interval that will draw is a mark, two positions, and a transform that produces a range. That is its minimum syllable. Ask for an interval without a transform and the engine refuses the sentence rather than drawing an empty panel. What it refuses shows that refusal.

This is the design choice that keeps the channel vocabulary small. The obvious alternative would add ymin and ymax as two more channels meaningful to a single mark, and a box plot would need five channels. Instead a transform invents the extents, exactly as bin invents a count, so the channel set never grows. box and ribbon read the same low and high values. The pair transform bounds(lower, upper) takes a low and a high you already have as two columns of the table, and Horizontal whiskers draws a coefficient plot with it.

13.7 Horizontal whiskers

Whiskers turn horizontal for the reasons bars do: the names are long, or there are many of them. A list of rows is then easier to scan than a row of columns. An interval takes its orientation from the bindings, the way a bar and a box do. Put the categories on y and the measured column on x:

  • R
  • Python
  • Julia
  • JavaScript
data(iris_flowers) + interval * confidence(0.95) + x(petal_length) + y(species) +
  x_label("Petal length (cm)") + y_label("Species") +
  title("The same 95% CI, horizontal")
(data(iris_flowers) + interval * confidence(0.95) + x(col.petal_length) + y(col.species) +
  x_label("Petal length (cm)") + y_label("Species") +
  title("The same 95% CI, horizontal"))
data(iris_flowers) + interval * confidence(0.95) + x(:petal_length) +
  y(:species) + x_label("Petal length (cm)") + y_label("Species") +
  title("The same 95% CI, horizontal")
plot(data(iris_flowers), layer(interval, confidence(0.95)),
  x(col.petal_length), y(col.species), x_label("Petal length (cm)"),
  y_label("Species"), title("The same 95% CI, horizontal"))

The caps turn too, since a cap always crosses the span at its end. The center dot stays at the center. Everything else in this chapter is unchanged: pattern, color and dodge behave the same whichever axis carries the categories, and so do caps and center, the two settings that Caps, or a linerange and Hiding the center dot explain.

This is the usual shape for a coefficient plot, where each row is a named estimate and the reader reads down the list of intervals. Estimates like these normally arrive already computed, from a model rather than from raw observations. That is what bounds is for: it reads two columns you already have as the low and the high, and computes nothing. The terms go on y. bounds supplies the values for the other axis, so there is no x() to write:

coefs: all 5 rows
term lo hi
Age 0.02 0.18
Education 0.31 0.55
Experience 0.11 0.29
Region: North -0.24 0.06
Region: South -0.05 0.21
  • R
  • Python
  • Julia
  • JavaScript
data(coefs) + interval * bounds(lo, hi) + y(term) +
  x_label("Effect on log wage") +
  title("A coefficient plot, from bounds you already have")
(data(coefs) + interval * bounds(col.lo, col.hi) + y(col.term) +
  x_label("Effect on log wage") +
  title("A coefficient plot, from bounds you already have"))
data(coefs) + interval * bounds(:lo, :hi) + y(:term) +
  x_label("Effect on log wage") +
  title("A coefficient plot, from bounds you already have")
plot(data(coefs), layer(interval, bounds(col.lo, col.hi)), y(col.term),
  x_label("Effect on log wage"),
  title("A coefficient plot, from bounds you already have"))

“Given the coefs table: intervals from lo to hi, y is term.”

Two intervals, Region: North and Region: South, run from a negative low to a positive high. Each one includes zero, so this data cannot say whether either effect is positive or negative.

An interval needs a number to span, so two categorical axes are refused, as they are on a bar and a box. What it refuses shows that refusal.

13.8 Splitting by color

A color says which whisker is which without reading the axis. The x axis already carries one category, so a channel is what separates a second one. color splits an interval into one whisker per group, the same categorical split line and bar make. The statistic is computed inside each group, so every group gets its own interval and its own hue. One legend names all of them:

  • R
  • Python
  • Julia
  • JavaScript
data(iris_flowers) + interval * confidence(0.95) + x(species) + y(petal_length) +
  color(species) +
  x_label("Species") + y_label("Petal length (cm)") +
  title("95% CI of mean petal length, by species")
(data(iris_flowers) + interval * confidence(0.95) + x(col.species) + y(col.petal_length) +
  color(col.species) +
  x_label("Species") + y_label("Petal length (cm)") +
  title("95% CI of mean petal length, by species"))
data(iris_flowers) + interval * confidence(0.95) + x(:species) +
  y(:petal_length) + color(:species) + x_label("Species") +
  y_label("Petal length (cm)") +
  title("95% CI of mean petal length, by species")
plot(data(iris_flowers), layer(interval, confidence(0.95)),
  x(col.species), y(col.petal_length), color(col.species),
  x_label("Species"), y_label("Petal length (cm)"),
  title("95% CI of mean petal length, by species"))

“Given the iris flowers: intervals derived by confidence at 95%, x is species, y is petal length, color by species.”

Oceania’s 1957 whisker looks like a single cap. The table has only two countries there, Australia and New Zealand. In 1957 their life expectancies were within a tenth of a year of each other. That span is shorter than a pixel, so the two caps draw on top of each other. In 2007 the two countries were a year apart, and the caps separate.

Width and opacity stay settings. A channel needs one value per row, and one whisker is a single stroke drawn from a whole group, so size and opacity have no rows to follow. style() sets them once for the layer:

  title("A heavier, one-color range")

13.9 Caps, or a linerange

The caps are the short lines across each end of a whisker. They are decoration rather than data, because they only emphasize where a whisker stops, and a crowded plot often reads more cleanly without them. So whether to draw them is a setting. style(caps = FALSE) drops them for a linerange, a whisker with no caps. caps = TRUE, the default, keeps the capped error bar. Here is the CI from Splitting by color with its caps off:

  • R
  • Python
  • Julia
  • JavaScript
data(iris_flowers) + interval * confidence(0.95) + x(species) + y(petal_length) +

No other mark has caps. On any other mark style(caps = ) is refused with direction, the same way a bar’s border_size is refused on a line. caps combines with range, confidence and deviation. So the error bar, the linerange and the pointrange are all the same mark. Only the transform and one setting change.

13.10 Hiding the center dot

A pointrange’s dot is the mean. Sometimes you want the whiskers without it, which is a bare error bar. style(center = FALSE) drops the dot, and center = TRUE (the default) keeps it. Like caps, it only hides: it cannot add a center to range, which has none to draw.

13.11 A dashed whisker

A dash separates one layer from another without a second color, and it still separates them when the plot is printed in black and white. A whisker is a stroke, so it takes style(pattern = ) the same way a line does. This is the settable rule: a dash patterns every path-stroke mark (line, step, interval, path, rule). The dash is drawn on the whisker span only. The caps and the center dot stay solid, since a dashed cap no longer looks like a cap:

13.12 A bar with its error bar

Two marks can answer two questions about the same groups. A bar shows where each group’s mean sits. An interval shows how well that mean is known. Layer them and you have a plot that appears throughout the social sciences, usually with a bare error bar rather than a pointrange:

“Given the iris flowers: bars derived by mean, colored lightgray, and also intervals derived by confidence at 95%, with center off, colored black, x is species, y is petal length.”

Each layer names its own statistic. bar * mean reduces each group to one number, and interval * confidence(0.95) computes the interval around that number. Both read the same column and report different things, and the sentence says which is which. The dot is turned off because the top of the bar already marks the mean, and the engine draws the two at exactly the same height.

A bar with an error bar is the figure where the three quantities from the opening are most often confused. The whisker looks the same whether it is a standard deviation, a standard error or a confidence interval. A caption has to say which one it is, because the drawing cannot. In gog the sentence has already said it. This one names confidence(0.95), and deviation in its place would give a different sentence and a much longer whisker.

A second category goes side by side, with the same dodge that separates grouped bars. Bind color to the bars and group to the whiskers. Both layers then split into the same slots, and the plot keeps one legend:

Oceania has both the shortest whisker and the longest, from the same two countries. A confidence interval from two values is wide, because two values say little about the spread. In 2007 Australia and New Zealand were a year apart, and the interval is thirteen years wide. In 1957 they were a tenth of a year apart, and the interval is still nine tenths of a year, more than twelve times the range that drew as a single cap above.

What this plot does not show is the data. Two groups can have the same mean and the same interval and still hold very different values, and a bar reports only the one number. Three layers instead of one mark draws the spread itself, and box draws five numbers at once.

13.13 What you can set

A setting changes how every whisker looks without reading a column, and each mark takes its own. These are an interval’s, with the values each accepts:

13.15 In short

An interval is geometry and nothing else. The transform says which two numbers it spans, and whether there is a center to draw. Caps, the center dot and the dash are settings, so none of the three reads a column.

13.16 What comes next

Which two numbers an interval spans is the transform’s answer, never the mark’s. Box answers it inside the mark, with the five-number summary that gives the box plot its name.
